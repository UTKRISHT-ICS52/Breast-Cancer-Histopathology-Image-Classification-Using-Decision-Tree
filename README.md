# Breast-Cancer-Histopathology-Image-Classification-Using-Decision-Tree

## 📌 Project Overview

This project implements a **Decision Tree Machine Learning algorithm** to classify breast cancer histopathology images into two categories: Non-Cancerous and Cancerous.

The project uses the Breast Histopathology Images (IDC) dataset. Histogram of Oriented Gradients (HOG) is applied for feature extraction, followed by Decision Tree classification using Python and Scikit-learn.

The primary objective is to explore traditional Machine Learning techniques for medical image classification and evaluate their performance using different classification metrics.

## 🎯 Objectives

- Classify histopathology images into cancerous and non-cancerous categories.
- Extract image features using Histogram of Oriented Gradients (HOG).
- Implement a Decision Tree classifier.
- Compare different maximum tree depth configurations.
- Evaluate model performance using standard ML metrics.
- Understand the impact of tree complexity on classification performance.

## 📂 Dataset Information

**Dataset:** Breast Histopathology Images (IDC)

**Source:** Kaggle  
https://www.kaggle.com/datasets/paultimothymooney/breast-histopathology-images

**Total Images:** 277,524

| Class Label | Category |
|---|---|
| 0 | Non-Cancerous |
| 1 | Cancerous |

Each image patch has an original dimension of 50 × 50 pixels.

## ⚙️ Project Workflow

### 1. Dataset Loading
Loaded histopathology images and extracted image paths, class labels, and patient IDs.

### 2. Data Visualization
Displayed sample images and examined the distribution of cancerous and non-cancerous classes.

### 3. Patient-Wise Data Splitting
Used `GroupShuffleSplit` to divide the dataset into training, validation, and testing partitions while keeping patient groups separate.

### 4. Balanced Dataset Preparation

| Dataset | Images |
|---|---:|
| Training | 4,000 |
| Validation | 2,000 |
| Testing | 2,000 |
| Total Selected | 8,000 |

Training data contains 2,000 images from each class. Validation and test data each contain 1,000 images from each class.

### 5. HOG Feature Extraction

Histogram of Oriented Gradients (HOG) was used to extract image features based on gradient directions and local texture patterns.

Configuration:
- Image Size: 64 × 64
- Orientations: 9
- Pixels per Cell: 8 × 8
- Cells per Block: 2 × 2
- Total Features: 1,764 per image

### 6. Decision Tree Classification

A Decision Tree classifier was implemented using Scikit-learn.

Different maximum depth values were evaluated:

- 5
- 10
- 15
- 20
- None

The best configuration was selected using validation F1-score.

### 7. Model Evaluation

The final model was evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- ROC Curve
- ROC-AUC

## 📈 Experimental Results

The following results were obtained during validation:

| Max Depth | Accuracy | Precision | Recall | F1-Score |
|---:|---:|---:|---:|---:|
| 5 | 56.75% | 54.68% | 78.90% | **64.59%** |
| 10 | 56.85% | 55.38% | 70.50% | 62.03% |
| 15 | 55.50% | 54.94% | 61.20% | 57.90% |
| 20 | 55.10% | 54.82% | 58.00% | 56.37% |
| None | 54.55% | 54.63% | 53.70% | 54.16% |

**Best Validation Configuration:** Maximum Depth = 5

The highest validation F1-score was 64.59%.

## 🔬 Limitations

- Decision Tree performance depends heavily on the quality of extracted features.
- HOG features may not capture all complex histopathological patterns.
- The experiment uses a balanced subset rather than the complete dataset.
- A single Decision Tree may be sensitive to variations in training data.
- The experimental results are not clinically validated.

## 📝 Conclusion

This project demonstrates the application of a Decision Tree classifier for breast cancer histopathology image classification using HOG-based feature extraction.

The experiment highlights the importance of feature engineering, patient-wise data splitting, hyperparameter tuning, and model evaluation.

The best validation configuration achieved an F1-score of 64.59% at a maximum tree depth of 5. This provides a baseline for further experimentation with ensemble learning and deep learning approaches.
